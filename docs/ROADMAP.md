# Roadmap

| Milestone | Goal | Done when |
|---|---|---|
| M0 | Measure the PSP | Decode time and throughput for H.264 and JPEG are recorded in `MEASUREMENTS.md` |
| M1 | Protocol | `sidescreen-proto` and its C counterpart agree on the framing, with tests on both sides |
| M2 | Host | Capture a monitor, scale to 480x272, compress, send over USB |
| M3 | PSP app | EBOOT.PBP receives, decodes and shows the stream, no menu |
| M4 | Presets | Source-size presets from `ARCHITECTURE.md`, stored per user |
| M5 | Polish | Pointer accuracy, reconnect, tray control |
